# AlignUp MVP – Core Features

## 1. Goal Alignment Engine
- Lets users define **core priorities** (e.g., career, wellness, relationships).  
- Maps each task or habit to one of these priorities.  
- Encourages reflection: “Is what I’m doing aligned with who I want to become?”

## 2. Daily Focus Planner
- Simple daily input system for tasks and intentions.  
- Supports tagging by energy level (High / Medium / Low).  
- Encourages balance — users can plan around energy, not just time.

## 3. Progress & Reflection Tracking
- Stores historical data to visualize trends in focus, completion rate, and wellness.  
- Prompts users to reflect on their performance and emotional state.  
- Enables consistent growth through feedback loops.

## 4. Notification & Nudge System
- Gentle reminders to realign when habits drift or focus fades.  
- Motivational prompts written in an affirming, human tone.  
- Can evolve into intelligent nudges powered by user data.

## 5. Modular Design for Scalability
- MVP runs locally in Python for speed and simplicity.  
- Architecture designed to expand into an **AI-assisted planner** later.  
- Each module is self-contained, making development lightweight and maintainable.
