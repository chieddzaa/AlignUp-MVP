# AlignUp – Productivity & Life Alignment App

AlignUp is a smart, calendar-based productivity and wellness assistant that helps you **align daily tasks with your energy, priorities, and values**.

### Features
- Checks which tasks are realistically achievable each day.
- Suggests optimal task timing based on energy patterns.
- Automatically reschedules lower-priority tasks.
- Daily devotionals and wellness check-ins.
- Sunday reset mode for weekly reflection.
- (Future) Mentor notifications, AI voice assistant, and group Align Circles.

### Tech Stack
- Python 3.x
- SQLite (for task tracking & data storage)
- Optional AI/ML libraries: pandas, numpy, scikit-learn
- FastAPI or Flask (for web interface, optional)
